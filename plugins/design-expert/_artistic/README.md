# Out of corpus — artistic pages

`elysian/` — a fictional neoclassical maison built from supplied plates: eight images,
four photographic transformations (slat shear, arch aperture, torn counter-pan,
letterform plate), dials 9 · 4 · 8. Self-contained, fonts and images in `assets/`.

**It is not part of the reference corpus** (`skills/design-web/references/refs-design/`)
and nothing in the plugin points here. It was pulled out because it had become the
default model: its whole central procedure transforms photographs, so a brief with no
photo library cannot use it, and pages were being derived from it by matching tone —
luxury calls to luxury — instead of by matching constraint.

**This folder is not a source of taste, and never a place to go looking for a procedure.**
The one case that authorises opening it: a brief that is explicitly artistic **and** ships
a real photo library. Anything else — read the corpus.
