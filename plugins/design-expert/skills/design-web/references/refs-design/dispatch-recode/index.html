FAQ

Questions & answers.

What does terminal-first actually mean?
Sodium was drawn for the shell before it was drawn for a browser; 62 MCP tools let Claude, Cursor, Codex or any agent run your list directly. A web panel exists as well, but it is optional, never the path.
How does the MCP integration work?
One guided command writes the server into your client config and stores a scoped token. From then on your agent sees campaigns, segments, workflows and analytics as ordinary tools, with organisation-level permissions applied on every call.
Do I have to be a developer to use it?
No. If you can hold a conversation with an AI assistant, you can run a Sodium list: the agent handles the commands. The CLI and the SDK are there for the people who want them.
What can I do with the 62 tools?
Draft and schedule campaigns, build and refresh segments, manage subscribers and custom fields, arm workflows, verify domains, and read every metric, each one callable in a sentence rather than a screen.
Is the free plan really free?
Yes: 3,000 emails a month, unlimited subscribers, no card. It is not a trial that expires; it is the shape of the product for a small list.
How is Sodium different from the usual platforms?
They price the audience and hide the work behind a panel. Sodium prices the sending, keeps every action scriptable, hosts in the EU, and never charges you for a subscriber who is simply on the list.
